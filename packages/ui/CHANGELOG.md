# Changelog

## 0.1.0

Initial release of the standalone AJS component library.

- Typed React primitives, Radix controls, tables, navigation, and member/admin patterns.
- ESM and CommonJS builds with TypeScript declarations.
- Compiled Tailwind CSS and configurable AJS design tokens.
- Consumer setup instructions and component usage examples.

This release has no production API integration. Some source application states were unavailable during inspection; see the workspace coverage documentation for limits.
