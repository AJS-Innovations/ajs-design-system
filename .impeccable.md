## Design Context

### Users
React developers adopting the standalone @ajsinnovations/ui library. They need to evaluate components, install the package, and reach practical documentation quickly.

### Brand Personality
Simple, confident, useful. The user requested a good, simple landing page based on the sibling ajs-website project.

### Aesthetic Direction
Use ajs-website's near-black surfaces, coral #FF4B4B accent, rounded navigation, and bold typography for the landing page. Retain the explicitly requested Switzer font. Keep existing light reference-derived documentation tokens at /docs.

### Design Principles
- Show actual library components and link directly to their documentation.
- Keep the landing page concise and responsive.
- Preserve production independence and avoid fabricated adoption claims.
- Keep brand landing styles separate from component tokens.
